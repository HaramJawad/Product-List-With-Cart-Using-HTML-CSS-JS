A small web project where you can see a list of products (desserts) and add them to a shopping cart. You can increase/decrease quantity, remove items, and confirm your order.

FEATURES:
Display products with images, names, and prices.
Add products to cart with a button click.
Increase or decrease quantity for each product in the cart.
Remove products from cart.
Shows total price of items in the cart.
Confirm order and see order summary in a modal.
Cart is saved in local storage, so it remembers your items even after refreshing.
Responsive (Not fully)

HOW TO USE:
Open index.html in your browser.
Click Add to Cart on any product.
Change quantity using + or - buttons.
Remove product by clicking the x icon.
Click Confirm Order to see order summary.
Click Start New Order to reset cart.

TECHNOLOGIES USED:
HTML,
CSS (Grid & Flexbox for layout, transitions for animation),
JavaScript (DOM manipulation, events, localStorage,arrays, array methods,functions)
